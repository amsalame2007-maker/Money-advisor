# Money-advisor (Finora)

Finora is an AI-powered personal financial advisor application designed to help you understand your money, plan your future, track expenses, and achieve your financial goals.

View your app in AI Studio: https://ai.studio/apps/c4843b5e-29fa-42ba-ae9d-6fc94d370cb8

## Run Locally

**Prerequisites:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Set your environment variables in `.env` (refer to [.env.example](.env.example))
3. Run the app:
   ```bash
   npm run dev
   ```
